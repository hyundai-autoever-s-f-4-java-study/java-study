# ☕ 자바(Java) 알고리즘 코딩 스터디

프로그래머스 및 백준 알고리즘 문제를 자바(Java)로 풀고 함께 리뷰하는 스터디입니다.
매주 정해진 분량의 문제를 풀고, Pull Request를 통해 코드 리뷰를 진행합니다.

## 📌 스터디 규칙
* **진행 기간:** 2026년 8월 7일 ~ (진행 중)
* **사용 언어:** Java ☕
* **과제 제출 마감:** 매주 목요일 오후 6시까지 PR 올리기

## 📂 폴더 구조 및 네이밍 규칙

자바는 클래스명과 파일명이 일치해야 하므로, **주차별 폴더 안에 본인 이름 폴더**를 만들고 그 안에 **문제별 폴더나 파일**을 생성합니다.

```text
📁 Repository
 ┣ 📂 week01
 ┃ ┣ 📂 hong       # 본인 영문 이름 또는 깃허브 ID
 ┃ ┃ ┣ 📂 카카오_인형뽑기  # 문제 이름으로 폴더 생성 (선택)
 ┃ ┃ ┃ ┗ 📄 Solution.java
 ┃ ┃ ┗ 📄 TargetNumber.java # 문제 이름으로 파일 생성 (선택)
 ┃ ┗ 📂 kim
 ┣ 📂 week02
 ...
```

## 🔄 깃허브 전체 진행 과정 (Workflow)

우리 스터디는 **Fork & Pull Request** 방식으로 진행됩니다. 
메인 저장소(Upstream)를 안전하게 보호하면서 각자 코드를 독립적으로 작성하기 위함입니다.

### 0. 초기 세팅 (스터디 시작할 때 딱 한 번만!)
1. 이 공통 저장소 우측 상단의 `Fork` 버튼을 눌러 자신의 계정으로 복사해 갑니다.
2. 자신의 계정에 복사된 저장소를 로컬 PC로 `clone` 합니다.
   ```bash
   git clone [자신의_저장소_URL]
   ```
3. 원본 공통 저장소(Upstream)를 로컬과 연결합니다.
   ```bash
   git remote add upstream [공통_저장소_URL]
   ```

### 1. 매주 과제 시작 전 (동기화)
내 로컬의 `main` 브랜치를 공통 저장소의 최신 상태와 똑같이 맞춥니다.
```bash
git checkout main
git pull upstream main
```

### 2. 새로운 주차 브랜치 생성 및 작업 
`main` 브랜치에서 계속 작업하면 이전 주차 PR이 아직 병합(Merge)되지 않았을 때 코드가 꼬이게 됩니다. `main`은 항상 깨끗하게 유지하고, 과제는 새로운 브랜치에서 진행해 주세요!

주차별로 새로운 브랜치를 만들어 작업합니다. (브랜치명 규칙: `주차/이름`)
```bash
git checkout -b week01/hong
```
지정된 폴더(`week01/hong/`)에 자바 코드를 작성하고 테스트를 완료합니다.

### 3. 작업 완료 후 Commit & Push
코드를 커밋하고 **자신의 저장소(Origin)**에 푸시합니다.
```bash
git add .
git commit -m "feat: 1주차 프로그래머스 문제 완료"
git push origin week01/hong
```

### 4. Pull Request (PR) 생성 및 템플릿 작성
1. 자신의 깃허브 저장소(Origin) 페이지로 이동하여 초록색 **Compare & pull request** 버튼을 클릭합니다.
2. PR 생성 화면에 진입하면 **미리 설정된 PR 템플릿(시간/공간 복잡도 등)이 자동으로 로드**됩니다.
3. 템플릿 내부의 `<!-- -->` 로 처리된 숨김 주석 가이드를 참고하여 채워주세요. (주석은 PR을 등록하면 자동으로 안 보이게 됩니다.)
4. 내용을 모두 작성했다면 PR을 생성합니다.
   * *도착지(base): Organization의 main 브랜치*
   * *출발지(compare): 내 저장소의 작업 브랜치*

### 5. 코드 리뷰 및 Merge
1. PR이 생성되면 스터디원들은 코드를 읽고 `Files changed` 탭에서 **코드 리뷰(Comment/Approve)**를 남깁니다.
2. 피드백을 받아 코드를 수정해야 한다면, 로컬에서 코드를 고치고 다시 `commit & push` 하면 해당 PR에 자동으로 반영됩니다.
3. 충분한 리뷰(Approve)가 모이면 스터디장(또는 담당자)이 메인 브랜치로 `Merge` 합니다.
